# Phase 1 开发计划

> 目标：先做“输入股票代码 -> 加入家庭股票池 -> 同步数据 -> 单股分析页”闭环。

## 1. 项目初始化

- 初始化前端项目：React + Vite + TypeScript。
- 建立 `docs/`、`src/`、`scripts/`、`data/`、`tests/` 目录。
- 配置基础测试命令。

## 2. 家庭股票池

- 支持录入股票代码。
- 支持股票状态：已持有、观察中、准备研究、暂停跟踪。
- 支持标签：爸爸关注、我关注、红利、AI、半导体、医药、新能源、风险复盘。
- 保存到 SQLite 或本地 JSON 的第一版数据层。

## 3. 数据同步

- A 股优先。
- 使用 Python + AKShare 同步行情、日线、周线和 60 分钟 K 线。
- 记录数据源、同步时间和失败原因。
- 输出数据健康状态。

## 4. 单股分析页

- 顶部显示当前结论、置信度和数据健康。
- 展示当前价格、关键价位、趋势状态和基础缠论结构。
- 先实现基础结论：数据不足、只观察不加仓、可继续持有、等待二买确认、可小仓试探、风险复盘。

## 5. 验收标准

- 家庭股票池输入 5-20 只股票后，系统能稳定读取和展示。
- 单只股票可以触发数据同步。
- 数据不足时系统明确提示，不强行下结论。
- 单股页面 3 分钟内能看懂当前状态、关键风险和下一步动作。
